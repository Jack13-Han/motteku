# 言語切り替えの確認

共通の `LanguageProvider` が言語を管理します。固定文字の辞書と人数・個数・日付の整形は `lib/messages.ts` と `lib/messages-extra.ts` にあります。新しい固定文字は英語をキーにして辞書へ追加し、画面では `t(key, params)` を使用してください。

初回の表示言語は、ブラウザの言語設定に関係なく日本語です。ユーザーが明示的に選択した日本語／英語はlocalStorageの `motteku-language` に保存され、再読み込み後も復元されます。保存済みの選択がない場合や無効な値の場合は、日本語を使用します。

## 自動確認

```powershell
node --test tests/i18n.test.cjs
node --experimental-strip-types --test tests/packing.test.mjs
npm run build
```

## ブラウザでの確認

1. ヘッダーの言語でEnglishを選びます。持ち物登録・設定・個人用／共有用の選択肢・進捗・エラーが英語になることを確認します。
2. バッグ、チャット、リマインダー、メンバー、予算、天気、履歴へ移動し、言語が変わらないことを確認します。
3. 日本語に切り替え、同じ画面の固定文字と日付が日本語になることを確認します。
4. Englishを明示的に選び、再読み込みとログイン・新規登録ページへの移動後も保存済みの英語が復元されることを確認します。日本語を選んだ場合も同様に確認します。認証画面にも言語セレクトがあります。
5. ブラウザの開発者ツールでlocalStorageの `motteku-language` を削除し、再読み込みします。ブラウザの優先言語が英語でも、初期表示が日本語になることを確認します。保存値を無効な文字列にした場合も日本語になることを確認します。
6. 名前が `Packed` のアイテム、日本語のバッグ名、メンバー名を登録します。言語を変えても入力した名前が変わらず、状態ラベルだけが変わることを確認します。
7. 5人中Packedが2人、Readyが1人なら、英語では `Ready: 3 of 5`、日本語では `準備完了：3 / 5人` が表示されることを確認します。
8. 天気を取得し、開発者ツールのNetworkでジオコーディングと `/api/weather` に `language=en` または `language=ja` が渡ることを確認します。予報の数値は共通で、天気名と日付を表示時に翻訳します。
9. AI提案を生成し、`/api/advice` のリクエスト本文に選択言語が含まれることを確認します。標準提案はその場で切り替わり、AI応答は言語ごとに管理され、未取得の言語では再取得します。既にリストに追加したアイテム名は変更しません。
10. 必須項目を空欄で送信し、バリデーションが選択言語になることを確認します。通知を有効にした場合、通知タイトルと本文も選択言語を使用します。

Firestoreの種類・状態コードを変更する移行処理はありません。ユーザー入力、写真名、チャット本文を自動翻訳する処理もありません。
